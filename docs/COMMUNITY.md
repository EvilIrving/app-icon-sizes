# Community plan (growth / community)

Solo-maintainer friendly. Honest engagement only. Facts from `GROWTH.md`.

## Repo readiness (done in-repo)

- [x] Clear README install + build from source
- [x] `CONTRIBUTING.md`
- [x] Bug + feature issue templates
- [x] `SECURITY.md`
- [x] GitHub topics (icons, tauri, ios, android, …)
- [x] Changelog / release notes scaffolding
- [x] `good first issue` tickets (#1–#4)
- [ ] Private vulnerability reporting enabled in GitHub Settings (optional toggle)

## Health signals to watch

| Signal | Healthy for a young project |
|---|---|
| Stars | Steady after each release announce; never buy |
| Issue response | Reply within 1–2 days when possible |
| Open/closed | Triage: close duplicates, label clearly |
| Contributors | Even 1–2 external PRs matter; credit in notes |

## Outside the repo (from GROWTH channels)

Use the **90/10 rule**: 90% helpful answers in the niche, 10% “I built this”.

| Place | How to engage |
|---|---|
| r/macapps | Answer Mac app questions helpfully; when relevant, mention a free icon-size exporter |
| r/iOSProgramming | Help with App Icon size questions; disclose authorship if linking the app |
| r/androiddev | Help with launcher icon size questions |
| Show HN | Only with a real, useful hook for makers. See `launch` |
| Product Hunt | Optional; needs polished GIF first (`visuals`) |

## awesome-* lists (honest PRs only)

Draft when the notarized macOS build is verified and README screenshots are fresh:

- awesome-tauri (if list accepts apps)
- awesome-mac (or similar Mac open-source lists)
- awesome-react (only if the list wants desktop tools; skip if off-topic)
- alternativeTo: free desktop alternative for multi-platform app icon export

Do not spam 50 directories. One honest PR per relevant list.

## Converting a launch spike

1. Pin an issue: “Roadmap / help wanted” after first Show HN or Reddit post
2. Label easy tasks `good first issue`
3. Thank every reporter by handle; credit merged PRs in release notes
4. Keep shipping small releases so the repo looks alive

## Soft star ask (allowed)

README and release notes may include one calm line: if the tool helps, a star makes it easier for others to find. Never run star-for-star schemes.
