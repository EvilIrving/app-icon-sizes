导出目标

  • iOS / macOS
  • Android
  • 图片集
  • Chrome 扩展
  • Favicon
  • 商店图
  • 仅本地 缩放与 ZIP 都在本机。无账号、不上云。
  • 一个 ZIP 勾选平台，一次导出。iOS 相关导出含 Contents.json。
  • 桌面界面 拖入 1024×1024 PNG，预览尺寸，导出。中 / EN。

安装

发行包

从 GitHub Releases 下载 macOS DMG 或 Windows 安装包。

releases/latest

macOS：DMG 与 App 均使用 Developer ID 签名、公证，并在发布前通过 Gatekeeper 验证。

源码构建

需要 Node 18+、pnpm、Rust。

pnpm install
pnpm tauri build

常见问题

免费开源吗？

是。MIT。

会上传图片吗？

不会。处理都在本机。

能导出哪些平台？

iOS / macOS 应用图标、Android 启动图标、图片集、Chrome 扩展图标，以及 Favicon 与商店图等。

为什么不是网站？

不上传、桌面工作流、一次打出多平台 ZIP；相关导出可带 Asset Catalog 元数据。

支持哪些系统？

Release 提供 macOS Apple Silicon DMG 与 Windows MSI / EXE；也可从源码构建。
