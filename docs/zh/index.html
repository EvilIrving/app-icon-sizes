常见问题

收费吗？

不收。免费，开源。

会上传我的图片吗？

不会。图片只在你自己的电脑上处理。

能导出哪些平台？

iPhone、iPad、Mac、安卓、多倍图、Chrome 扩展、网站图标和商店图。

原图用多大比较好？

建议用 1024×1024 的 PNG，导出更清楚。

我的电脑能用吗？

Mac（Apple 芯片）和 Windows 都可以直接下载安装。
