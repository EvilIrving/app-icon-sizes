What it is

Icon Sizes is a cross-platform app icon generator that runs as a local Tauri desktop app: drop in a 1024×1024 PNG, pick presets, export one ZIP. It is free under MIT and does not upload your images.

What you get

Icon Sizes focuses on the differentiators that matter for shipping icons: local processing, multi-platform presets, and Asset Catalog friendly output.

Local-first

Resize and ZIP export on-device. No account, no cloud round-trip, no surprise uploads.

Multi-platform ZIP

Apple app icons, Android mipmaps, image sets, Chrome extension icons, favicon and store options in one export.

Asset Catalog friendly

Includes Contents.json for iOS-oriented exports so the result drops into Xcode more cleanly.

Free and open source

MIT licensed. Read the code, fork it, or build from source with pnpm and Rust.

Desktop, not a tab

Tauri shell with drag-and-drop workflow and a live preview grid.

Bilingual UI

English and Chinese interface for day-to-day use.

Compared with web icon generators

Icon Sizes is a local alternative to web app-icon generators: you trade zero-install convenience for privacy and desktop presets.

Approach Strength Tradeoff
Web icon generators Zero install You upload source art to a third party
IDE / design plugins Deep workflow integration Often tied to one platform or a paid suite
Icon Sizes Local, multi-platform ZIP, free Requires downloading a desktop app

Install

Icon Sizes ships via GitHub Releases for macOS and Windows. Source builds need Node.js 18+, pnpm, and Rust.

Download

Open the latest GitHub Release and pick macOS DMG or Windows installer.

FAQ

Is Icon Sizes free and open source?

Yes. It is free under the MIT license.

Does Icon Sizes upload my images?

No. Processing stays on your computer.

Which platforms can Icon Sizes export?

iOS and macOS app icons, Android launcher icons, image sets, Chrome extension icons, plus favicon and store image options.

How is Icon Sizes different from web icon generators?

No upload requirement, desktop workflow, and multi-platform presets packed into one ZIP, including Asset Catalog metadata where relevant.

What operating systems does Icon Sizes run on?

macOS (Apple Silicon DMG) and Windows (MSI / EXE) from Releases, or build from source with pnpm and Rust.
