FAQ

Is it free and open source?

Yes. MIT license.

Does it upload my images?

No. Everything stays on your computer.

Which platforms can it export?

iOS / macOS app icons, Android launchers, image sets, Chrome extension icons, favicon and store options.

Why not a website?

No upload requirement, desktop workflow, multi-platform ZIP with Asset Catalog metadata where relevant.

Which OS?

macOS Apple Silicon DMG and Windows MSI / EXE from Releases, or build from source.
