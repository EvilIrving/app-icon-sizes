One PNG in. Every app-icon size out.

Icon Sizes is a free desktop app that generates icons for iOS, macOS, Android, Chrome extensions, and image sets from a single source image. Everything runs locally on your machine.

Download latest release View on GitHub

macOS DMG (Apple Silicon) and Windows MSI / EXE on GitHub Releases.

What you get

Built for indie and mobile developers who need Asset Catalog and mipmap-ready output without sending artwork to a website.

Local-first

Resize and export on-device. No account, no cloud round-trip, no surprise uploads.

Multi-platform ZIP

iOS/macOS sizes, Android mipmaps, image sets, Chrome extension icons, favicon and store options in one export.

Asset Catalog friendly

Includes Contents.json for iOS-oriented exports so the result drops into Xcode more cleanly.

Free and open source

MIT licensed. Read the code, fork it, or build from source with pnpm and Rust.

Desktop, not a tab

Native-feeling Tauri shell with drag-and-drop workflow and a live preview grid.

Bilingual UI

English and Chinese interface for day-to-day use.

Compared with web generators

Web icon tools are convenient. Icon Sizes trades install friction for privacy and desktop presets.

FAQ

Is Icon Sizes free?

Yes. It is free and open source under the MIT license.

Does it upload my images?

No. Processing stays on your computer.

Which platforms can it export?

iOS and macOS app icons, Android launcher icons, image sets, Chrome extension icons, plus favicon and store image options.

How is it different from web icon generators?

No upload requirement, desktop workflow, and multi-platform presets packed into one ZIP, including Asset Catalog metadata where relevant.
